The Flood Severity Forecasting System is a hybrid machine learning–based project developed to predict reservoir water levels and classify flood risk using real-time meteorological and hydrological data. Floods are among the most destructive natural disasters, and traditional threshold-based monitoring systems often fail to provide timely and accurate warnings due to rapidly changing climatic conditions. This project integrates reservoir storage metrics, rainfall intensity, temperature, and other environmental parameters to build an intelligent prediction framework. A hybrid ensemble approach combining Random Forest and XGBoost algorithms is used to improve prediction accuracy, reduce overfitting, and capture complex nonlinear relationships between hydro-meteorological variables. The system performs data collection, preprocessing, feature engineering, model training, and severity classification to generate actionable flood risk levels such as Low, Medium, High, and Critical. Developed using Python with libraries like Pandas, NumPy, Scikit-learn, XGBoost, and Flask, the system provides a scalable and interpretable solution for early warning and disaster management. By leveraging machine learning and real-time data integration, this project enhances proactive flood preparedness and supports effective decision-making for reservoir management and community safety.
